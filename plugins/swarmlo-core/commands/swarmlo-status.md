---
name: swarmlo-status
description: Show Swarmlo system health, MCP server status, and active agents
---
$ARGUMENTS
Run diagnostics and show system status.
```bash
npx swarmlo-cli@3.39.1 doctor
npx swarmlo-cli@3.39.1 status
```
To auto-fix issues, run `npx swarmlo-cli@3.39.1 doctor --fix` separately.
